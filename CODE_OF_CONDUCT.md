# Code of Conduct

Be kind. This is a joke repo, and it only works if people feel safe joking in it.

## Do

- Make fun of code, tools and trends. Not of people.
- Say what you actually ran and what actually passed.
- Assume a bug report was written in good faith, even when the tool said `ok ✅`.
- Credit the originals. Every port is a love letter to something real.

## Don't

- Harass, insult or exclude anyone.
- Post other people's private information.
- Send slop that is not harmless: files deleted, real network calls, real credentials.

## Enforcement

Maintainers can edit, hide or remove comments, issues and pull requests that break these rules, and can block people who keep doing it. To report a problem, contact the repository owner through GitHub.
