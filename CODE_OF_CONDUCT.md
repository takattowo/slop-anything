# Code of Conduct

Be kind, be precise, be honest.

## Do

- Critique code, tools and designs, never people.
- Say what you actually ran and what actually passed.
- Assume good faith in bug reports.
- Credit the original tools. Every port exists because the original is worth reimplementing.

## Don't

- Harass, insult or exclude anyone.
- Post anyone's private information.
- Submit changes that break the harmlessness rules: writes outside the data folders, network access, credentials.

## Enforcement

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules, and may block people who repeat them. To report a problem, contact the repository owner through GitHub.
